# openSUSE setup
## Update
```sh
sudo zypper refresh && sudo zypper dup -y
```

## Install Packages

```sh
sudo zypper install -y noto-fonts fira-code-fonts git-lfs lazygit gh zoxide fzf inkscape neofetch btop rsync tailscale mpv ripgrep eza fd curl wget docker docker-compose neovim steam firefox chromium fastfetch krita libreoffice gamemode lutris flatpak rustup kitty gcc gamescope opi
```


```sh
opi vscode
```

```sh
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

```sh
flatpak install -y flathub com.discordapp.Discord org.localsend.localsend_app
```
